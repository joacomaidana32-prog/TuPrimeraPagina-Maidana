Proyecto: Gestión de Casa de Música 🎸
Este proyecto es una aplicación web desarrollada en Django siguiendo el patrón MVT para la gestión de instrumentos, marcas y clientes.

📋 Funcionalidades
Herencia de Plantillas: Uso de un archivo base.html para mantener un diseño consistente.

Modelos: Gestión de 3 entidades (Instrumento, Marca y Cliente).

Formularios: Carga de datos para cada uno de los modelos.

Búsqueda: Buscador funcional de instrumentos por nombre.

🚀 Instrucciones para probar el proyecto
Para ver las funcionalidades en orden, te sugiero seguir estos pasos:

Inicio: Ingresa a la URL principal para ver la bienvenida.

Carga de Marca: Ve a + Marca y registra una (ej: Fender, Gibson, Yamaha).

Carga de Instrumento: Ve a + Instrumento y carga uno asociado a una marca (ej: Stratocaster).

Carga de Cliente: Ve a + Cliente para registrar un usuario de la tienda.

Búsqueda: Haz clic en el botón 🔍 Buscar e ingresa el nombre del instrumento que cargaste antes para verificar que la base de datos responde correctamente.
